# Sobre esta cópia do código

Durante esta execução, `experimento_mamba3.py` ganhou o trecho que, para dados com ruído, mede o erro também contra a posição sem ruído. O processo já em andamento usou a versão anterior, mas o hash em `execucao.json` foi calculado no fim e corresponde a esta cópia. A execução de referência (`resultados/duffing-v1`) não tem `diagnostico/saida-sem-ruido.npz`, então o trecho novo não teria sido executado: o comportamento das duas versões é o mesmo para estes dados.
